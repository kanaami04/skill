# AIっぽいUIを避けるためのアンチパターン

以下を絶対禁止とはしない。**採用する場合は、目的と必要性を説明できることを条件とする。**
採用した場合は、`templates/comparison.md` の「アンチパターンに該当する採用」欄に理由を残す。

## レイアウト

- 意味の異なる情報をすべて同じ形のカードに入れる。
- どの画面でも同じ3列・4列のカードグリッドを使う。
- すべてのページに大きなタイトルと説明文を置く。
- 情報量にかかわらず、過剰に広い余白を設ける。
- 実際の利用目的より、見栄えを優先した構造にする。

## 色と装飾

- 理由なく紫や青のグラデーションを多用する。
- 背景、カード、ボタン、バッジのすべてに装飾を加える。
- すべてのコンポーネントを大きな角丸にする。
- 意味のないグロー、ぼかし、影を追加する。
- 強調色を多用し、視覚的な優先順位を曖昧にする。

## タイポグラフィと情報設計

- すべてを大きな見出しと短いキャッチコピーで表現する。
- 実際には必要な情報がないのに、見た目を埋めるための説明文を追加する。
- 実際のデータや要件を確認せず、ダミーの指標やグラフを並べる。
- アイコンやバッジで表現する必要がないものまで装飾する。
- 見た目を整えるために、操作や情報の分かりやすさを犠牲にする。
